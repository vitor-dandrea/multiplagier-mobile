# Apresentação — Multiplagier Mobile 2.1.0

Slides HTML estáticos (fora do runtime Flutter) para a apresentação do **projeto Interdisciplinar**.

## Como abrir

1. Abra `index.html` no navegador (duplo clique ou arrastar para o Chrome/Edge).
2. Ou, na pasta deste diretório:

```bash
# PowerShell
start index.html
```

Não precisa de `npm` nem de servidor. Diagramas são SVG embutidos (funcionam offline).

## Navegação

| Ação | Como |
|------|------|
| Próximo | →, ↓, Espaço, Page Down, clique na metade direita |
| Anterior | ←, ↑, Backspace, Page Up, clique na metade esquerda |
| Ir ao slide N | URL `#s1` … `#s11` |
| Início / fim | Home / End |
